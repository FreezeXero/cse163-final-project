# CSE 163 Final Project

UW CSE 163 Autumn 2026 Final Project — Group Data Analysis.

## Project files

- `data_cleaning.py` contains rental data preparation code.
- `wage_affordability.py` contains the wage and rent affordability analysis.
- `test_wage_affordability.py` contains checks for the affordability calculation.
- `Datasets/` contains the supplied rental and minimum-wage data files.
